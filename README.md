# Shoev Switcher

Нативный автоматический переключатель русской и английской раскладок для macOS.

Shoev Switcher работает локально, живёт в строке меню и исправляет текст после
пробела или знака препинания. Настраиваемое двойное нажатие Shift принудительно
конвертирует выделенный текст, текущее или последнее слово.

## Скачать

[Скачать Shoev Switcher для macOS](https://github.com/TiDazai/Shoev-Switcher/releases/download/v0.4.4-alpha/Shoev-Switcher.dmg)

Откройте DMG, перенесите Shoev Switcher в `Applications` и выдайте приложению
доступ к мониторингу ввода и универсальному доступу. Текущая тестовая сборка не
нотарифицирована Apple, поэтому при первом запуске может потребоваться команда
«Всё равно открыть» в разделе «Конфиденциальность и безопасность».

## Возможности

- автоматическое исправление RU ↔ EN;
- отмена ошибочного автоисправления одним Backspace без создания скрытых исключений;
- ручная конвертация выделения, текущего или последнего слова;
- выбор двойного левого или правого Shift для ручной конвертации;
- самообучение после повторных ручных исправлений;
- настоящий переход на нужный источник ввода macOS;
- флаг текущей раскладки рядом с указателем мыши над полями ввода;
- запоминание раскладки отдельно для каждого приложения;
- мягкий языковой профиль приложений для неоднозначных слов;
- отключаемое уведомление `было → стало` после исправления;
- подробные настройки с отдельным выключателем для каждой необязательной функции;
- меню без иконки в Dock;
- исключения по приложениям;
- зашифрованный локальный журнал;
- поиск и фильтры в дневнике;
- просмотр статистики самообучения и удаление выученных правил;
- редактор правил «никогда не менять», «всегда менять» и личных словарей;
- импорт и экспорт правил в JSON;
- полный встроенный корпус: 668 543 русских и 307 629 английских слов;
- редкие формы, имена, названия и бренды из энциклопедических, новостных и
  разговорных источников;
- контекст последних слов и встроенные частые фразы для корректного распознавания коротких `я`, `не`, `hi`;
- пополнение личных словарей прямо из дневника;
- полный дневник только по явному включению;
- автоматический запуск при входе в macOS;
- универсальная сборка для Apple Silicon и Intel;
- работа без облачных API, телеметрии и подключения к интернету.

## Системные требования

- macOS 13 или новее;
- включённые источники ввода English и Русский;
- разрешения Input Monitoring и Accessibility.

Shoev Switcher не обрабатывает ввод, пока включён Secure Event Input, а также в полях, которые macOS помечает как защищённые. Терминалы, IDE и менеджеры паролей рекомендуется оставлять в исключениях как дополнительную меру.

## Сборка из исходников

Откройте `Package.swift` в Xcode или используйте терминал:

```bash
swift test
./scripts/setup-local-signing.sh # один раз на Mac
./scripts/build-app.sh
open "dist/Shoev Switcher.app"
```

Готовое приложение появится в `dist/Shoev Switcher.app`.

Для создания DMG:

```bash
./scripts/build-app.sh
./scripts/create-dmg.sh
```

Результат: `dist/Shoev-Switcher.dmg`.

Для публичной сборки нужен сертификат `Developer ID Application`. Сборка
подписывается с Hardened Runtime, после чего DMG отправляется Apple через
`scripts/notarize.sh` и получает прикреплённый нотариальный билет. Тег `v*`
запускает тот же процесс в GitHub Actions, если в репозитории настроены секреты
подписи и Apple ID.
