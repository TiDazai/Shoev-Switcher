# Shoev Switcher — раскладка и орфография

Разработано компанией **SHOEV SYSTEMS**. Автор — **Shoev Timur (TiDazai)**.

Shoev Switcher is an offline Russian–English keyboard layout and spelling app for macOS, made by SHOEV SYSTEMS.

Shoev Switcher предназначен только для **macOS 26 и новее**. Опубликованная версия доступна как [предрелиз 0.8.0](https://github.com/TiDazai/Shoev-Switcher/releases/tag/v0.8.0). Обновлённый дизайн для 0.8.1 пока находится в работе и не опубликован отдельным релизом. Исправление при обычном наборе в Microsoft Word было проверено в 0.7.1; совместимость других текстовых полей зависит от редактора. Работа в поле ввода Codex не подтверждена.

## Просто продолжай писать

Shoev Switcher для macOS объединяет два независимых модуля в одном приложении. Светлый платиновый фон, серебристые поверхности и золотые акценты. Логотип — платиновая кошка Shoev Systems без стрелок и квадратной подложки, в том числе на иконке приложения. Статичная текстура не использует анимацию. В строке меню — только кошка; через неё можно открыть окно или включить и выключить модули.

| Модуль | Что делает |
| --- | --- |
| Switcher | Исправляет неверную раскладку и переключает RU ↔ EN |
| Spell | Исправляет опечатки, заглавные буквы и помогает с русской пунктуацией |

Можно оставить только Switcher, только Spell, включить оба или выключить оба. В окне есть отдельные настройки модулей и три раздела: журнал событий, дневник личных правил и словарь RU/EN. Закрытие окна не завершает приложение.

| Набрано | Получится |
| --- | --- |
| `ghbdtn` | привет |
| `f vj;yj` | а можно |
| `руддщ` | hello |

Корректные английские слова вроде `hi` не нужно переводить. Для неоднозначных слов учитываются частоты, последние слова фразы и личные правила — автоматическое распознавание не всегда может угадать намерение.

Enter, Shift+Enter и Tab проходят в приложение без перехвата: отправку сообщения, перенос строки и переход между полями определяет сам редактор. Автоматическое исправление выполняется на пробеле или знаке препинания, не на Enter.

## SHOEV SYSTEMS

Приложения SHOEV SYSTEMS для работы с русским и английским текстом:

- **Shoev Switcher** — исправление неверной раскладки и автоматическое переключение RU ↔ EN.
- **[Shoev Spell](https://github.com/TiDazai/Shoev-Spell)** — исправление опечаток, заглавные буквы и помощь с русской пунктуацией.

С версии 0.6.0 для macOS функции Spell входят в Shoev Switcher. Отдельный Shoev Spell сохранён как самостоятельный продукт. Если он запущен, встроенный модуль Spell приостанавливается, чтобы два обработчика не исправляли текст одновременно. Завершить отдельный Spell можно кнопкой в главном окне; его приложение и данные не удаляются.

## Установка на Mac

1. Открой [DMG для macOS 26+](https://github.com/TiDazai/Shoev-Switcher/releases/download/v0.8.0/Shoev-Switcher.dmg) и перетащи приложение в **Applications**.
2. Запусти Shoev Switcher.
3. Разреши **Мониторинг ввода** и **Универсальный доступ** в настройках macOS.
4. Убедись, что добавлены русская и английская раскладки.

Требуется **macOS 26+**. **Apple Silicon и Intel** — в одном приложении; версии macOS до 26 больше не поддерживаются. Архивные релизы сохраняют прежние системные требования.

Текущая общедоступная сборка не нотарифицирована Apple. При первом запуске macOS может её заблокировать: используй «Всё равно открыть» в «Системные настройки → Конфиденциальность и безопасность», если доверяешь источнику.

## Под рукой

- **Автоматическое RU ↔ EN** — словарь уже внутри, сеть не нужна.
- **Независимый Spell** — орфография, заглавные буквы, пунктуация и отдельные исключения по приложениям.
- **Главное окно** — обзор, настройки Switcher/Spell, отдельный журнал, дневник правил и словарь.
- **Двойной Shift** — вручную перевести выделение, текущее или последнее слово. Левый или правый Shift выбирается в настройках.
- **Backspace после исправления** — вернуть исходное слово без скрытых исключений.
- **Флаг возле мыши** — язык ввода над текстовым полем, без привязки к каретке.
- **Настройки по функциям** — контекст, флаг, уведомления, память раскладки, обучение и журнал можно отключить отдельно.
- **Исключения по приложениям** — терминалы и IDE исключены по умолчанию.
- **Журнал** — события Switcher и Spell со статусами: ожидает, сохранено, отменено, удалено/изменено, не подтверждено.
- **Дневник** — только личные правила, их источник, модуль и область; редактирование, приостановка, импорт и экспорт JSON.
- **Самообучение** — три независимых подтверждённых повторения; удаление не считается согласием, автоматическое исправление не обучает само себя.
- **Словарь** — весь встроенный корпус, отдельно русский и английский; поиск по началу слова и страницы по 200 записей. Личные слова отмечены звездой и полужирным начертанием.
- **Автозапуск и память раскладки** — по желанию.

## Самообучение без поспешных правил

После подтверждённой вставки результат временно ожидает проверки. Для обычного подтверждения он должен остаться в том же поле минимум две секунды и после него должны появиться два завершённых слова; Enter подтверждает оставленный результат перед действием редактора. Удаление или изменение отменяет наблюдение. Навигация, смена поля и неопределённый результат не обучают приложение.

Доказательством для нового правила служит действие человека: ручная конвертация, сохранённая явная отмена или близкое ручное исправление результата. Три независимых подтверждения одной пары создают правило, сначала для этого приложения и модуля. Между подтверждениями нужно не менее пяти секунд; быстрые переключения и одинаковые квитанции не учитываются. Самостоятельно исправленное приложением слово **не** объявляется правильным лишь потому, что приложение его вставило. Явная отмена приостанавливает соответствующее выученное правило; ручные правила имеют приоритет.

Дневник содержит готовые личные правила, а неподтверждённые наблюдения видны отдельно. Слово из правила и выученная замена отмечаются в личной части словаря; область и модуль сохраняются. Вручную добавленное слово действует как явное подтверждение написания. Встроенный корпус остаётся read-only. Старые правила сохраняются при обновлении; непроверенные автоматические правила прежней версии приостановлены до ручного одобрения. Новая политика применяется к новым наблюдениям.

## Словари внутри

**7 120 939 записей:** 4 020 787 русских и 3 100 152 английских слов и словоформ. В корпус входят морфология, имена, фамилии, географические названия, бренды, технические термины, сленг и ненормативная лексика.

Это большой корпус, а не обещание знать каждое существующее слово. Личные словари дополняют его без пересборки приложения. Данные и их лицензии перечислены в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Текст остаётся на устройстве

Нет облачных API и телеметрии. Журнал, дневник правил, личные слова и наблюдения хранятся локально с шифрованием AES-GCM. Запись обычного набора в журнал выключена по умолчанию. Для резервной вставки буфер обмена временно используется и затем безопасно восстанавливается.

Перед заменой Switcher проверяет текущее поле, курсор и исходный текст через Accessibility. В защищённых полях, при Secure Event Input и там, где приложение не позволяет безопасно прочитать и изменить текст, автоматическая замена пропускается. Совместимость зависит от конкретного редактора и поля; универсальная работа во всех приложениях не гарантируется.

Автоматическое исправление выполняется после обработки настоящего пробела или знака препинания; изменившийся текст или курсор отменяет отложенную замену. С версии 0.6.4 настоящий разделитель не выделяется и не вставляется заново: заменяется только слово или фраза, затем проверяется положение курсора после разделителя. Если редактор игнорирует прямую замену, Switcher пробует Cmd+V в подтверждённое выделение. Буфер временно содержит исправление и восстанавливается после подтверждения вставки, только если пользователь не скопировал что-то новое. Все доступные форматы сохраняются; слишком большой или недоступный буфер не используется. Не подтверждённая редактором вставка не вызывает преждевременного восстановления буфера. Switcher и Spell используют общую блокировку, чтобы не менять его одновременно.

## Разработка

macOS 26+ — Swift Package, Xcode 26+ и соответствующие Command Line Tools:

```bash
./scripts/prepare-lexicon.sh
swift test
./scripts/create-dmg.sh
```

Результат: `dist/Shoev-Switcher.dmg`. Скрипт создаёт свежую универсальную сборку, проверяет подпись приложения и контрольную сумму образа. Для сохранения разрешений при локальной разработке можно один раз выполнить `./scripts/setup-local-signing.sh`.
