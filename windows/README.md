# Shoev Switcher для Windows

Windows-версия использует локальный словарь на 7,1 млн русских и английских слов

## Возможности

- автоматическая конвертация RU ↔ EN после пробела или знака препинания;
- ручная конвертация текущего слова двойным правым Shift;
- реальная смена активной раскладки Windows после исправления;
- контекст последних слов и привычного языка программы;
- отмена автоисправления клавишей Backspace;
- запоминание раскладки для каждой программы;
- самообучение после повторных ручных исправлений;
- флаг раскладки рядом с курсором над текстовым полем;
- полноценные окна настроек, дневника и обучения;
- уведомление `было → стало`;
- управление из области уведомлений и автозапуск;
- локальная работа без облачных API и телеметрии.

Ввод через RDP, Parsec и другие средства удалённого доступа поддерживается. Shoev Switcher пропускает только события, которые создал сам, чтобы не возникал цикл повторных замен.

Стандартные парольные поля пропускаются. Терминалы, IDE и популярные менеджеры паролей входят в исходный список исключений. Windows запрещает обычному процессу подменять ввод в приложении с правами администратора; при необходимости оба процесса должны работать с одинаковым уровнем прав.

## Сборка

Нужен .NET SDK 8 или новее:

```powershell
dotnet build ShoevSwitcher.Windows/ShoevSwitcher.Windows.csproj -c Release -p:SelfContained=false
dotnet run --project ShoevSwitcher.Windows/ShoevSwitcher.Windows.csproj -c Release --no-build -p:SelfContained=false -- --self-test
dotnet publish ShoevSwitcher.Windows/ShoevSwitcher.Windows.csproj -c Release -r win-x64 --self-contained true
```

При отправке тега `v*` GitHub Actions собирает `Shoev-Switcher-Windows-x64.zip` и прикладывает его к тому же релизу, что и macOS DMG.
