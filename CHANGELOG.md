# История изменений

## 0.5.2 — 12 октября 2026

- Кошка в оригинальном логотипе перекрашена в золото и бордо, фон прозрачный.
- Обновлены иконки macOS и Windows, а также цветной значок в строке меню macOS.
- Единый источник логотипа для README, иконки приложения и меню.
- Исходный серебристый логотип сохранён отдельно.

## 0.5.1 — 12 октября 2026

### macOS

- Замена текста через Accessibility вместо синтетической клавиши A/Ф и серии Backspace.
- Перед заменой проверяются поле ввода, позиция курсора и точный исходный текст.
- Отмена Backspace работает только в исходном поле с неизменённым текстом.
- Удаление, навигация и восстановление обработчика очищают устаревший буфер.
- Нажатия Shift при обычном наборе не вызывают ручную конвертацию.
- События мыши объединяются; выключенный флаг не опрашивает Accessibility.
- Таймауты и проверка типов ответов Accessibility ограничивают зависания и ошибочные преобразования.
- Последние записи дневника сохраняются при выходе; неуспешная транзакция не теряет очередь.
- Защита от запуска двух экземпляров приложения.
- Проверка SHA-256 встроенного словаря и чистая сборка DMG без остатков предыдущих версий.

### Windows

- Исправлен размер Win32 INPUT для SendInput; добавлена проверка в self-test.
- Неуспешная вставка больше не считается успешным исправлением.
- Устаревшая отмена сбрасывается после нового слова, навигации и смены окна.

### Проект

- Оформление SHOEV SYSTEMS с оригинальным логотипом.
- Релизная сборка DMG и Windows-архива с проверками перед публикацией.
- Регрессионные тесты удаления, отмены, смены поля и сохранения дневника.

Автоматическая замена на macOS требует доступного для чтения и редактирования поля Accessibility. Если проверить текст нельзя, приложение оставляет ввод нетронутым.
