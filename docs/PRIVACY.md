# Приватность и дневник

Shoev Switcher получает доступ к событиям клавиатуры, поэтому приватность является частью архитектуры, а не дополнительной настройкой.

## Основные правила

- никакой сети и телеметрии;
- никаких журналов в iCloud;
- текущий буфер очищается при смене приложения, клике мыши, навигации и системных shortcuts;
- при Secure Event Input и в защищённых полях обработка полностью приостанавливается;
- индикатор раскладки проверяет только тип элемента под курсором и не читает его текст;
- языковой профиль приложения хранит Bundle ID и счётчики RU/EN, но не сами слова;
- приложения можно исключать по Bundle ID;
- содержимое дневника шифруется AES-GCM;
- ключ хранится отдельным локальным файлом с правами `600` и не синхронизируется между устройствами;
- очистка дневника не удаляет пользовательские правила и словари.

## Два уровня записи

Журнал исправлений включён по умолчанию и содержит только исходное/исправленное слово, время и приложение.

Полный дневник выключен по умолчанию. После явного включения он сохраняет завершённые слова, введённые с клавиатуры. Он не может достоверно включать вставки из clipboard, диктовку или текст, изменённый другим приложением.

## Хранение

База расположена в:

```text
~/Library/Application Support/Shoev Switcher/journal.sqlite3
```

Текстовые поля журнала, статистики самообучения и пользовательских правил
хранятся зашифрованными. Служебные поля — время, Bundle ID, язык и тип события —
не шифруются, чтобы база оставалась простой и быстрой.

Для ручной конвертации выделения приложение кратковременно получает только
выделенный текст через Accessibility и сразу заменяет его локально. Выделение не
добавляется в самообучение; если журнал исправлений включён, операция сохраняется
в его зашифрованной локальной базе. В сеть текст не отправляется.

Экспорт правил выполняется только вручную в выбранный пользователем файл JSON.
Этот файл не шифруется: его можно перенести на другой Mac или прочитать обычным
редактором. Само приложение никуда его не отправляет.
