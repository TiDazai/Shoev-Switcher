Обновлённый дизайн: светлая платиново-серебристая тема с золотыми акцентами. Та же платиновая кошка Shoev Systems — без стрелок и квадратной подложки. Убраны информационные подсказки и лишние подписи.

Основные технологии и возможности:

- **Swift, SwiftUI и AppKit** — нативный интерфейс, отдельные настройки Switcher и Spell, журнал, дневник и словарь.
- **Core Graphics и Accessibility** — глобальная обработка клавиатуры и проверка поля, текста и позиции курсора перед заменой. При невозможности безопасной проверки ввод не изменяется; защищённые поля пропускаются.
- **Carbon Text Input Services** — переключение RU/EN, горячие клавиши и память раскладки для приложений.
- **Локальные алгоритмы** — анализ слов, частот и контекста для раскладки; подбор исправлений опечаток, регистра и пунктуации для Spell.
- **SQLite** — встроенный офлайн-корпус из 7 120 939 русских и английских слов и словоформ. Индексный поиск, кэширование и постраничный просмотр без загрузки всего словаря в память.
- **Адаптивное самообучение** — личные правила после трёх независимых подтверждений; удаление слова само по себе не создаёт исключение. Ручные правила имеют приоритет.
- **CryptoKit: AES-GCM и HMAC-SHA256** — шифрование личного текста и защищённые индексные ключи. Данные обрабатываются на Mac, без облачных API и телеметрии; JSON-экспорт не зашифрован.
- **ServiceManagement, Swift Package Manager и XCTest** — автозапуск, универсальная сборка Apple Silicon / Intel и регрессионные тесты.

Требуется macOS 26+. Совместимость автоматических исправлений зависит от возможностей конкретного редактора. Предрелиз без Developer ID и нотариализации Apple.
